# Проверенные дефекты

Все пункты ниже функциональные, сторона FRONT. Дизайнерские дефекты не заявляются.

## C-1. Последняя отметка пропадает при уходе с экрана (высокий)
- Предусловие: рабочий workspace, открыт экран логирования.
- Шаги: вызвать отметку, размонтировать компонент до истечения 500 мс.
- Было: upsertLog вызван 0 раз. Доказательство: evidence/C-1-unmount-before.txt.
- Ожидается: начатое сохранение не отменяется сменой экрана.
- Верификация: реальный хук React, управляемый Promise; после исправления незавершённая запись завершается после unmount. Исправлено общей очередью без debounce.

## C-2. Конкурирующие записи используют общий снимок для отката (высокий)
- Шаги: изменить одну/две даты, удержать первый ответ, отправить второе изменение; отклонить один запрос.
- Было: параллельные запросы, общий snapshot сбрасывается первым ответом, каждое завершение вызывает refetch.
- Ожидается: последнее действие определяет итог; ошибка одной записи не стирает другую.
- Верификация: log-writer.test.ts проверяет сериализацию, оба порядка ошибок, два отказа одной даты, batch rollback и данные после refetch. Исправлено. Исходные гонки подтверждены анализом кода; сетевое воспроизведение старой версии отдельно не проводилось.

## C-3. Нельзя снять недельную/месячную галочку другого дня (высокий)
- Шаги: сохранить выполнение в день A, перейти к дню B того же периода, снять галочку.
- Было: записывается ноль в B; значение A остаётся и задача остаётся выполненной.
- Ожидается: галочка отражает весь период и должна сниматься.
- Верификация: evidence/task-cross-day-before.txt и task-cross-day-after.txt; браузерный локальный сценарий. Исправлено; batch upsert сохраняет все изменяемые даты вместе.

## C-4. Редактор смешивает исходные строки с новыми ID периода (высокий)
- Шаги: открыть A, сменить входной набор на B, сохранить.
- Было: строки сохраняются от A, deletes вычисляется по B; также действия во время запроса могли терять новый черновик.
- Ожидается: сохранение относится только к открытой форме.
- Верификация: editor-components.test.tsx проверяет неизменный набор удаления и блокировки; браузер подтвердил невозможность сменить период в редакторе. Исправлено.

## C-5. Ошибка удаления невидима вне редактора (средний)
- Шаги: получить ошибку saveGoals при удалении из списка.
- Было: saveGoals.isError выводился только внутри HorizonEditor.
- Ожидается: пользователь видит неудачное действие.
- Верификация: оба экрана передают ошибку в scaffold, компонентный тест подтверждает вывод текста. Live production fault injection не выполнялся. Исправлено.

## C-6. Невозможная дата и некорректный вес проходят локальную проверку (средний)
- Шаги: указать 2026-11-31, отрицательный/нечисловой вес или дробь с запятой.
- Было: regex проверял лишь формат даты; parseFloat обрезал строку и дробь с запятой.
- Ожидается: реальные даты и число 0..100, понятная ошибка до запроса.
- Верификация: editor-components.test.tsx и локальная браузерная проверка даты. Исправлено.

## C-7. Профиль показывает "Сохранено" после изменения имени (средний)
- Шаги: сохранить имя, дождаться успеха, снова изменить поле.
- Было: сообщение успеха оставалось возле несохранённого значения.
- Ожидается: успех относится к текущему значению, новый ввод убирает его.
- Верификация: auth-screens.test.tsx, последовательность success -> change. Исправлено; имя отправляется после trim.

## Отклонённые и непроверенные гипотезы
- Недобор кольца без всех горизонтов: так задумано, DECISIONS.md.
- Временная ошибка загрузки production: после reload восстановилось; первопричина не установлена.
- Пересчёт истории после изменения target/endDate: нужны продуктовые правила.
- XP floating-point, logout errors, параллельная геймификация: гипотезы вне подтверждённого набора; см. summary.md.
