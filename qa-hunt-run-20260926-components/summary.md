# Novigo: проверка компонентов и исправления

Прогон 26–29 сентября 2026. Ветка dev. Изменения локальные; push, deploy и миграции не выполнялись.

## Результат

Итог: **88/88 тестов, 13/13 наборов; TypeScript, ESLint, web export и git diff --check завершились успешно.**

Исправлены потеря отложенной отметки при размонтировании экрана, конкурирующие записи прогресса, снятие недельной/месячной галочки с другого дня, небезопасная смена контекста редактора, невидимая ошибка удаления, валидация дат/весов и устаревшее подтверждение сохранения имени.

- Записи прогресса отправляются сразу и последовательно общей для аккаунта очередью. Ошибка откатывает только затронутые значения; ожидающие изменения сохраняются при перечитывании workspace.
- Снятие галочки и массовая очистка задач отправляют все затронутые даты одним upsert. Новая SQL-миграция не нужна.
- Пока открыт редактор, календарная навигация заблокирована. Во время сохранения заблокированы поля, кнопки и отмена. Удаление рассчитывается по исходному набору ID.
- Ошибки удаления видны на основном экране. Несуществующие даты и некорректные веса отклоняются до запроса; десятичная запятая поддерживается.
- В профиле отправляется нормализованное имя; сообщение "Сохранено" убирается при следующем изменении поля.

## Наблюдения браузера

- Локально цель перешла с 0/3 на 1/3, дневное кольцо на 33%; после reload осталось 1/3.
- Недельная задача была выполнена вчера. Нажатие сегодня убрало галочку, недельное кольцо изменилось с 70% на 30%.
- При открытом редакторе нажатие следующего периода не изменило "21–27 сентября". Новая тестовая задача успешно появилась в списке.
- Пустая цель показала "У каждой цели должно быть название". Дата 2026-11-31 показала "Укажи существующую дату в формате ГГГГ-ММ-ДД".
- В локальной консоли ошибок не наблюдалось.
- Production сначала показывал "Не удалось загрузить профиль" с Failed to fetch/AbortError. После reload 28 сентября цели и задачи загрузились. Причина временного сбоя не установлена; это не доказательство дефекта компонента или неприменённой миграции.

## Границы проверки и оставшиеся вопросы

- Не выполнены записи в production, SQL-проверка применённых миграций и RLS между разными аккаунтами. Локальный HTTP API имитирует ответы и НЕ проверяет Supabase/Postgres.
- Не проверены доставка recovery email/SMTP, реальная смена пароля, native-сборки iOS/Android, разрешения, haptics и реальные анимации.
- ThemeProvider/сохранение темы в AsyncStorage и RootGate не получили отдельных интеграционных тестов; доступные браузерные пути и сборка их затронули, но полного покрытия нет.
- Очередь переживает смену экранов в работающем приложении. Она не является offline-хранилищем и не гарантирует доставку при принудительном закрытии вкладки/процесса.
- Изменение target/endDate существующей цели и влияние на исторические логи требуют продуктового решения. Семантика истории не менялась.
- Подозрение на граничную точность бонусов XP, ошибки logout и конкурирующие вторичные пересчёты геймификации не подтверждались отдельными воспроизведениями; не включены в исправленные дефекты.
- Отсутствие 100% кольца без целей всех горизонтов соответствует требованиям 60/40 и 80/20. Не исправлялось как баг.
- Макет Figma отсутствует; дизайнерские расхождения не заявляются.

## Повтор локального прогона

Из корня проекта в первом терминале:

```bash
node qa-hunt-run-20260926-components/local-api.mjs
```

Во втором:

```bash
EXPO_PUBLIC_SUPABASE_URL=http://127.0.0.1:9040 EXPO_PUBLIC_SUPABASE_ANON_KEY=local-qa-fixture npx expo start --web --port 8087 --host localhost
```

Открыть localhost:8087, вход qa@novigo.test с любой непустой тестовой строкой пароля. Данные существуют только в памяти локального процесса. Не использовать этот API и его параметры для production.
