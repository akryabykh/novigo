## Крупная история №3: safe-refactor (2026-07-03, в рабочем дереве `dev`)
Рефакторинг по 14 пунктам + правка «24-часовой лаг». Продуктовая математика колец сохранена
(проверено 59 тестами). Ключевое:
- **Веса**: единый `equalWeights`/`redistributeWeights` (десятые, сумма ровно 100 для 3/6/7/9).
- **Запрет правок**: `canLogOn`/`isPeriodEditable` — нельзя писать в будущее, вне периода цели и в
  период, закрытый >24ч назад; такие показываются read-only, bulk — только по записываемым.
- **Optimistic-логирование**: переписано на кэш React Query (cancel→snapshot→patch→rollback→
  invalidate), убраны вечные overrides, чистка debounce на unmount, баннер ошибки сохранения.
- **Атомарность**: RPC `save_horizon` (миграция 0007) — updates+deletes+creates в одной транзакции
  с проверкой auth.uid(); серверные CHECK (title, task.target=1) и триггер лог-в-периоде.
- **Геймификация** вынесена из основного сохранения (её ошибка не роняет лог/цели); XP уважает
  startDate/endDate.
- **Дедуп экранов** в `features/calendar` (format/useCalendar/useOptimisticLog/CalendarScaffold),
  без over-abstraction.
- **RootGate**: различает profile loading / not-found / request-error (при ошибке — retry, не
  редирект в complete-profile). Шрифты/splash: не виснут при ошибке загрузки шрифтов.
- **Чистка**: удалены select.ts, gamification-UI, мёртвые zod-схемы, per-row репо-функции.
- **Тесты**: `npm test` (jest+babel, node) — 8 сюит / 59 тестов.
- Гейт зелёный: tsc 0, eslint 0, jest 59/59, expo export ok. `npm audit --omit=dev` — 11 moderate
  из транзитивного uuid в тулинге Expo (пре-существующее, не наш код).

## Крупная история №1: «ничего не грузится / вечные скелетоны» (РЕШЕНО)
Две первопричины, обе устранены и лежат в проде:
- **Дедлок supabase-js на вебе** через `navigator.locks` (логин-POST 200, промис висит). Починка —
  **no-op lock** в `src/core/data/supabase.ts`.
- **RU throttling Cloudflare** (Supabase спрятан за Cloudflare, росс. провайдеры режут скорость) —
  «вчера летало, сегодня висит». Починка — **same-origin Vercel-прокси** `/supabase-api/*`
  (`resolveClientUrl` + `vercel.json`). Диагностировать похожее как СЕТЬ, не как регрессию кода.
- Диагностика — через MCP `claude-in-chrome` в реальном браузере пользователя (headless в песочнице
  врёт: там сеть к Supabase таймаутит, хотя у пользователя быстро).

## Крупная история №2: редизайн в календарную модель (СДЕЛАНО)

- Убраны: сессии, админка, вкладка «Прогресс».
